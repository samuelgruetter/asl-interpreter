Attempt 3:

opam switch create AsliSwitch 4.09.0

for each of these package X, run `opam show X`
menhir ocamlfind ott linenoise pprint z3.4.7.1 zarith
and pick the latest version before Jan 1, 2020.
Except that z3 is so old that it requires Python 2.7 which is not available on Ubuntu any more, so just drop z3 because we shouldn’t need it (?)
linenoise: 1.3.1 even though that’s a bit too new, but 1.3.0 requires <ocaml.4.09
potential incompat reason: `opam show ott.0.30` says “conflicts    "pprint" {>= "20220103"}”
resulting in new command:
opam install menhir.20190924 ocamlfind.1.8.1 ott.0.30 linenoise.1.3.1 pprint.20180528 zarith.1.9.1
well, z3 is actually needed, so just
opam install z3
which picks z3.4.13.0-3
export DYLD_LIBRARY_PATH=`opam config var z3:lib`
now:
make asli

opam install bignum.v0.13.0

true: package(bignum)
